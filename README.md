# wheat-STB-matrices

Data and code used for the study : "Plant-plant interactions in varietal mixtures directly modulate wheat susceptibility to Septoria tritici blotch".

The script "Matrix_wheat_STB.Rmd" contains all code for the statistical analysis presented in the manuscript (main text & supplementary information). 
This script uses files "Bread_wheat_STB.csv" and "Durum_wheat_STB.csv" as inputs.
